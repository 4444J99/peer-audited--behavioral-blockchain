# Styx, in one page

**Audience:** Jessica
**Purpose:** a private, travel-ready product demonstration — not a public launch or a real-money offer.

## The simple idea

Styx gives a person a clear way to make a commitment, provide a record of what happened, and review the result. The demonstration uses fictional people, synthetic commitments, and test credits so that the flow can be discussed without exposing anyone's data or moving actual money.

## What you can see now — Working today

- A synthetic participant can sign in, view a commitment, see a check-in history, and inspect a test-credit ledger entry.
- A synthetic proof record is attached to a commitment and has a review outcome.
- A synthetic coach account has an assigned-client view. The demonstration is about the agreed commitment signals, not unnecessary personal detail.
- An enterprise-style screen shows aggregate synthetic program data with tenant-scoped access.

## What the test-money beta would be — Test-money beta

The next external step is a small, consented, hosted cohort using test-money only. It needs a real hosted environment, Stripe test credentials, verified geography behavior, consent and support operations, and a fresh passed live-stack receipt. It does not charge participants, settle funds, or make a clinical promise.

## What is later — Future enterprise capability

Employer use is a later evaluation path, not a completed procurement offering. It requires privacy and security review, operational controls, hosting proof, and the buyer's procurement process. The screen is useful to show the direction, not to claim that those gates have been cleared.

## Why the accounting boundary is visible

The demo ledger uses test credits. That makes the accountability flow inspectable while keeping the payment and custody boundary honest: there is no card charge, transfer, stored value, payout, or real-money balance in this demonstration.

## How to run it

From the repository root, start the demo with `npm run demo:launch`. For a clean synthetic reset, use `npm run demo:reset`; then confirm it with `npm run demo:verify`. Open `/tour` for the guided version and `/circles` for the seeded demo index.

## What this is not

It is not a real-money launch, a clinical service, an outcome claim, a public pricing page, or proof that enterprise procurement is complete.

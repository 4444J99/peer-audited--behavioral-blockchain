# Appendix C: State Blocklist Justification Table

This document summarizes state-level regulatory rationales for jurisdictional restrictions.

| State / Jurisdiction | Status | Primary Statutory Rationale | Legal Authority |
|----------------------|--------|----------------------------|-----------------|
| Washington (WA) | Blocked | Strict statutory prohibition on online chance/skill wagering hybrids | RCW 9.46.240 |
| Arizona (AZ) | Restricted | Specific licensing mandate for fantasy/skill contest platforms | A.R.S. § 5-1201 |
| Montana (MT) | Blocked | Prohibition on internet-based gambling/wagering activities | MCA § 23-5-112 |
| Nevada (NV) | Restricted | Mandatory gaming commission registration requirement | NRS Chapter 463 |
| All Other US States | Allowed | Predominance test for skill-based contracts satisfied | Uniform Commercial Code / State Common Law |
